# SimpleStore

A full-stack product management application built with the MERN stack.

The application allows users to create, view, update, and delete products through a responsive interface.

## Features

- View all products
- Create new products
- Update existing products
- Delete products
- Product cards with name, price, and image
- Responsive layout
- Light and dark mode
- Toast notifications for actions
- RESTful API
- MongoDB database

## Tech Stack

### Frontend

- React
- React Router
- Chakra UI
- Zustand
- React Icons

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- dotenv
- Nodemon
